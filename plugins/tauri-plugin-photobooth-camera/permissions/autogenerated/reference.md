## Default Permission

Window behaviour (keep awake, immersive) and the back-button listener used by the booth UI. Camera and USB commands are not exposed to the WebView.

#### This default permission set includes the following:

- `allow-window-set-keep-screen-on`
- `allow-window-set-immersive`
- `allow-register-listener`
- `allow-remove-listener`
